## 二、难度曲线数学模型

### 选型理由：S 曲线（Sigmoid）

S 曲线完美匹配 Roguelike 地牢探险的体验节奏：
- **前段平缓**（第1层）：教学期，让新手安全学习
- **中段陡升**（第2~3层）：引入复杂机制，难度快速攀升，心流建立
- **后段趋稳但极高**（第4~5层）：极限挑战，区分高手与普通玩家

### 数学公式

```
D(x) = D_max / (1 + e^(-k * (x - x_mid)))

其中：
  D(x)   = 第 x 个房间的难度值（1~10）
  D_max  = 10（最大难度）
  k      = 0.12（陡度系数，适配8-12房间/层的更大地牢）
  x_mid  = 30（中点房间，约第3层中期，总房间数的~55%处）
  e      = 自然常数 2.71828
```

### 难度组成公式（每个房间的具体难度由以下权重因子组合）

```
房间实际难度 = 0.30 × 敌人强度 
             + 0.25 × 环境危害（陷阱/元素/虚空侵蚀）
             + 0.20 × 敌人数量
             + 0.15 × 空间压缩度
             + 0.10 × 时间压力

各因子范围: 0~10
```

### 层间难度缩放公式（对齐GDD数值）

```
敌人HP缩放    = baseHP × (1 + 0.4 × (层数-1))   → 1.0x / 1.4x / 1.8x / 2.4x* / 3.0x
敌人攻击缩放  = baseATK × (1 + 0.3 × (层数-1))  → 1.0x / 1.3x / 1.6x / 2.0x* / 2.5x*
敌人速度缩放  = baseSpeed × (1 + 0.15 × (层数-1))
掉落品质缩放  = 稀有+概率 × (1 + 0.15 × (层数-1))

* 第4-5层使用GDD指定倍率（略高于线性公式），体现后期难度跳跃
```

### 3.3 房间路线结构

每层8-12个房间通过BSP算法生成，具有**分支路线**结构：

```
第1层示例（引导式，分支少）:
  [入口] → [A]→[B]→[C] ─→ [D]→[E]→[F] ─→ [G]→[H] → [Boss]
                       ↘          ↗
                        [D']→[E'] ┘

第2~4层示例（多分支选择）:
  [入口] → [区域1: 3-4房间] ─→ [区域2: 3-4房间] ─→ [区域3: 2-3房间] → [Boss]
           (2~3条路线可选)     (路线交汇/分叉)     (汇聚向Boss)

第5层（压迫式线性）:
  [入口] → [A]→[B]→[C]→[D]→[E]→[F]→[G]→[H] → [Final Boss]
  虚空侵蚀持续收缩可活动区域，无处可逃
```

**路线规则：**
- 第1层：**引导式**（主路线+少量可选分支，教学期不让玩家迷路）
- 第2~4层：**多分支**，BSP生成2~3个区域，玩家在节点选择路线
- 第5层：**线性汇聚**（压迫感递增，虚空侵蚀持续）
- 地图上可预览房间类型图标（战略决策）
- 每条路线保证公平——不同路线的总战斗难度相当

## 七、随机生成规则

### 7.1 房间生成规则

```javascript
// 每层生成逻辑伪代码（对齐GDD: BSP算法）
function generateFloor(floorNumber) {
  const config = FLOOR_CONFIG[floorNumber];
  
  // 1. BSP空间分割：生成房间布局
  const bspTree = generateBSP(config.mapWidth, config.mapHeight, config.minRoomSize);
  
  // 2. 确定房间数量（8-12）
  const roomCount = random(config.minRooms, config.maxRooms); // 8~12
  
  // 3. 放置必出房间
  let rooms = [...config.requiredRooms]; // 必出房间
  
  // 4. 填充随机房间（按概率池）
  const remainingSlots = roomCount - rooms.length;
  for (let i = 0; i < remainingSlots; i++) {
    rooms.push(weightedRandom(config.roomPool));
  }
  
  // 5. BSP分配房间到空间节点
  assignRoomsToBSPNodes(bspTree, rooms);
  
  // 6. 生成走廊连接
  generateCorridors(bspTree);
  
  // 7. 放置Boss房在最远端
  const bossRoom = { type: 'BOSS', boss: config.boss };
  placeBossAtFarthestNode(bspTree, bossRoom);
  
  // 8. 生成路线结构
  const routes = generateRoutes(bspTree, config.routeType);
  
  return { rooms: bspTree.getAllRooms(), routes, corridors: bspTree.getCorridors() };
}
```
