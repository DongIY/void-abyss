### 2. 🎨 策划部门（游戏策划 + 交互设计）

**GDD Lite 设计要点**：
- **3 可玩角色**：虚空斩者(Warrior)、星骸猎手(Ranger)、深渊法师(Mage)
  - 每角色 3 技能 + 独特战斗风格
  - Warrior: 高生存高近战、旋风斩/冲锋/狂暴
  - Ranger: 高速高射速、散射/陷阱/暗影箭
  - Mage: 技能爆发、火球术/冰霜新星/雷暴

- **5 层地牢结构**：
  1. 星尘走廊 (L1) — 入门教学层
  2. 暗物质矿脉 (L2) — 难度上升，新增幽灵敌人
  3. 虚空裂缝 (L3) — 陷阱引入，潜行者敌人
  4. 时空扭曲 (L4) — 高难度，瞬移敌人
  5. 深渊之心 (L5) — 最终 Boss，三阶段战斗

- **19 种敌人**：8 常规 + 5 精英 + 5 Boss + 1 变体
- **7 种 AI 行为**：游荡/冲锋/包夹/远程/潜行/瞬移/巡逻
- **5 种 Boss AI**：环绕射击/冲锋破坏/召唤支援/瞬移爆发/三阶段终极

**交互体验设计**：
- 键鼠操控：WASD 移动 + 鼠标瞄准/攻击 + 空格闪避 + QER 技能
- 移动端虚拟摇杆 + 操作按钮适配
- 随机事件选择界面（3 选项）+ 商店购买界面
- 天赋选择（3 选 1 升级机制）

**数值平衡**：
- 敌人 HP/ATK 随层数线性增长（mul = 1 + floor × 0.15~0.3）
- Boss HP 从 200 到 1200 递进
- 道具稀有度概率：普通 100% → 稀有 50% → 史诗 20% → 传说 5%
- 经验需求指数增长（×1.5/级）
- 暗物质经济：击杀掉落 + 死亡保留 + 胜利双倍

### 3. 💻 主程部门（Core Programmer）

**架构设计**：
```
game.js 模块架构:
├── Audio Manager  — Web Audio API 合成音效 (14种)
├── FX Manager     — 粒子系统 (200上限) + 浮动文字 + 屏幕震动
├── DATA           — 全量游戏数据定义
├── Utilities      — 8个工具函数
├── Global State   — 游戏状态 + 存档 + 每局运行数据
├── Dungeon Gen    — 随机地牢生成 (房间图 + 敌人配置 + 陷阱)
├── AI Controller  — 12种AI行为 (7常规 + 5Boss)
├── Game Engine    — 核心更新循环 + 战斗系统 + 技能系统
│   ├── 元素系统   — 4元素 + 4反应 (蒸发/超导/碎冰/湮灭)
│   ├── 道具系统   — 19件装备 + 效果叠加 + Synergy
│   ├── 天赋系统   — 12种天赋 × 3树
│   ├── 商店系统   — 随机商品 + 金币交易
│   ├── 事件系统   — 3种随机事件 + 选择分支
│   └── Meta系统   — 永久升级 + 成就追踪 + 存档
├── Renderer       — Canvas 2D 渲染引擎
│   ├── 背景星空   — 动态粒子
│   ├── 房间渲染   — 墙壁/网格/门/Boss出口
│   ├── 实体渲染   — 玩家/敌人(含血条+状态)/弹幕/陷阱/区域
│   └── 小地图     — 实时房间探索图
├── UI Manager     — 屏幕管理 + HUD更新 + 面板渲染
├── Input Handler  — 键鼠 + 触摸 + 虚拟摇杆
├── Save/Load      — localStorage 持久化
└── Init           — 加载动画 + 按钮绑定 + 游戏主循环
```

**技术亮点**：
1. **IIFE 模块化**：所有子系统封装为立即执行函数，避免全局污染
2. **零依赖**：纯 JavaScript，无第三方库
3. **程序化音效**：Web Audio API 实时合成 14 种音效，零音频文件
4. **性能优化**：粒子池上限 200，对象复用，Camera culling
5. **响应式**：自适应窗口大小 + 移动端完整支持

**待优化项**：
- 弹幕密集时可考虑空间分区（QuadTree）
- Boss 动画可增加更多视觉反馈
- 可考虑 Web Worker 处理 AI 计算
