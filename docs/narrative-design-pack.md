## 一、叙事基调定义

### 1.1 世界观概述

**「深渊领域」** 是一个关于 **坠落、探索、与轮回** 的故事。

在已知宇宙的边缘，存在一道永恒的裂缝——**「始源裂隙」(The Primordial Rift)**。裂隙之下是无尽的深渊，深渊中蕴含着宇宙诞生前的原始力量：**暗物质、虚空能量、以及被遗忘的时间碎片**。

千万年来，无数文明的探索者坠入裂隙，试图触及深渊之心中蕴藏的「**起源之核**」——传说中能够重塑现实的终极力量。没有人回来过。但每一位坠入者的灵魂都化为了深渊的一部分：化为星尘走廊中飘浮的微光，化为暗物质矿脉中沉默的结晶，化为虚空裂缝中回荡的低语。

玩家扮演的是最新的坠入者——一个被深渊选中（或被深渊诱惑）的灵魂。每一次死亡，深渊都会将你的记忆碎片吞噬，但也会将前人的力量碎片归还给你。**这就是轮回的代价与馈赠。**

### 1.2 叙事基调三棱镜

| 维度 | 基调 | 表现 |
|------|------|------|
| **孤独感** | 宇宙深处的绝对孤独 | 无同伴系统，NPC稀少且神秘，环境音大于对话 |
| **探索欲** | 对未知的恐惧与渴望并存 | 每层主题递进，叙事碎片化分布，世界观拼图感 |
| **轮回感** | 死亡不是结束而是新的开始 | 死亡文案带哲学意味，跨局叙事推进，NPC记忆延续 |

### 1.3 叙事语言风格

- **中文**：古典诗意 + 宇宙科幻。用短句营造节奏感，避免长句。意象多于说理。
- **英文**：简洁、有力、略带诗性。偏好盎格鲁-撒克逊词根（短词）而非拉丁词根（长词）。
- **禁用**：网络流行语、卖萌用语、过度解释性文本、感叹号滥用。
- **关键词频**：深渊、虚空、星尘、回响、湮灭、裂缝、寂静、坠落。

## 五、逃离倒计时文案

### 5.1 深渊崩塌逃离序列

> 设计规格（同步关卡蓝图）：
> - 击败最终Boss后触发，60秒倒计时反向穿过5层
> - 每层 3 秒通过窗口，文案出现于进入每层的第 1 秒
> - 每句 ≤15 个中文字，确保紧张中快速阅读

**第 5 层 → 第 4 层（深渊之心崩塌）**
```json
{
  "zh": "深渊之心碎裂——快跑！",
  "en": "The Heart shatters — RUN!"
```

## 附录A：文案风格指南（给开发者的备注）

### A.1 字数限制速查

| 场景 | 中文字数限制 | 英文词数限制 | 显示时长 |
|------|-------------|-------------|---------|
| 层级入口引言 | ≤30字 | ≤15词 | 2-3秒 |
| 层级过渡文案 | ≤20字 | ≤12词 | 2秒 |
| Boss出场台词 | ≤30字 | ≤15词 | 2秒 |
| Boss阶段台词 | ≤40字 | ≤20词 | 出现在屏幕上方 |
| Boss被击败台词 | ≤50字 | ≤25词 | 慢速打字效果 |
| 逃离倒计时文案 | ≤15字 | ≤8词 | 1秒 |
| 滞留催促文案 | ≤10字 | ≤6词 | 即时 |
| 死亡文案 | ≤50字 | ≤25词 | 3秒 |
| NPC首次见面 | ≤100字 | ≤50词 | 对话框 |
| 事件描述 | ≤80字 | ≤40词 | 事件卡 |
| 虚空低语 | ≤25字 | ≤12词 | 3秒后淡出 |
| 道具获取提示 | ≤25字 | ≤12词 | 2秒 |

### A.2 文本显示方式

| 类型 | 显示方式 | 字体 |
|------|---------|------|
| Boss标题/名字 | 大字居中 + 打字效果 | --font-ui (Orbitron) |
| Boss台词 | 屏幕上方半透明条 | --font-body (Rajdhani) |
| 层级引言 | 全屏居中 + 淡入淡出 | --font-body (Rajdhani) |
| NPC对话 | 底部对话框 + 逐字显示 | --font-body (Rajdhani) |
| 事件描述 | 事件卡中央 | --font-body (Rajdhani) |
| 虚空低语 | 屏幕边缘 + 半透明 + 浮动 | --font-ui (Orbitron) |
| 伤害数字 | 弹出 + 重力下落 | --font-damage (Orbitron) |
| 系统提示 | 屏幕中央 + 缩放弹出 | --font-ui (Orbitron) |

### A.3 语言切换规范

- 所有文案均以 JSON 格式存储 `{ "zh": "...", "en": "..." }`
- 运行时根据 `settings.language` 读取对应字段
- 切换语言时所有 UI/对话/事件文案即时切换
- 中英文文案长度可能不同，UI 组件需支持自适应宽度
